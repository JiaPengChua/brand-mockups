One Ada agent, two brands

Both pages run the same agent (journify-sandbox). Each one passes a brand meta field. MHholidays also passes its own branding to adaEmbed.start(). Switching pages resets the conversation.

Notes


    
 
  • branding only changes how the chat looks. The agent never sees it. Greetings, answers and handoffs branch on the brand meta field.
    • 
 
  • If you set launcher.backgroundColor without launcher.iconUrl, the launcher keeps the dashboard icon on the new colour.
    • 
 
  • Both pages share one origin, so they share Ada's stored session. When the brand changes, the page calls reset({ metaFields: { brand }, resetChatHistory: true }). Branding stays in place after a reset.
